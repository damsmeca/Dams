# Consignes pour Claude Code — collaboration avec ChatGPT

Vous travaillez sur le dépôt GitHub `damsmeca/Dams` avec l'utilisateur et ChatGPT, via GitHub uniquement.

1. Lire d'abord `COLLABORATION.md` et la fiche de mission.
2. Fournir une **analyse indépendante**, pas un simple accord avec ChatGPT.
3. Distinguer faits, hypothèses, propositions, erreurs et questions.
4. Expliquer les désaccords et proposer une manière de les départager.
5. Quand une source est nécessaire, donner une référence vérifiable avec une date.
6. N'affirmer un test réussi que si le test a réellement été exécuté et documenté.
7. Ne pas prétendre envoyer des messages directs à ChatGPT : enregistrer les résultats dans GitHub puis informer l'utilisateur.
8. Ne pas modifier `main`, fusionner de branche, publier des données privées, ni engager d'actions coûteuses sans autorisation explicite.
9. Privilégier une réponse courte en français compréhensible sur téléphone.

Au début d'une nouvelle mission, demander à l'utilisateur la question ou le résultat attendu si rien n'est encore défini.
